# FP3級 学習サイト 2025

FP3級（ファイナンシャルプランナー3級）試験対策のための実践的な学習サイトです。2025年の試験形式に対応した過去問題と詳しい解説を提供します。

## 特徴

- **6つの試験分野を完全カバー**
  - ライフプランニングと資金計画
  - リスク管理
  - 金融資産運用
  - タックスプランニング
  - 不動産
  - 相続・事業承継

- **実践的な過去問題**
  - 各分野12問ずつ、合計72問を収録
  - 実際の試験に基づいた問題形式
  - 詳しい解説付き
  - **毎回ランダムに出題**されるため繰り返し学習に最適

- **インタラクティブな学習体験**
  - 分野別の学習が可能
  - リアルタイムで正答数を確認
  - 自動採点と結果表示
  - **正解・不正解が一目でわかる**視覚的フィードバック
  - 不正解の問題番号を表示し、復習をサポート

- **お気に入り機能**
  - 重要な問題や復習したい問題を**お気に入り登録**
  - ★ボタンで簡単に登録/解除
  - **ローカルストレージに自動保存**（ページを閉じても保持）
  - お気に入り数をリアルタイム表示

## 使い方

1. ブラウザで `index.html` を開く
2. 学習したい分野のボタンをクリック
3. 問題に回答していく
4. 解説を読んで理解を深める
5. 結果を確認して復習

## 試験情報（2025年）

### 試験形式
- CBT（Computer-Based Testing）方式
- 毎月実施
- 全国47都道府県のテストセンターで受験可能

### 合格基準
- **学科試験**: 60点満点中36点以上（60%）
- **実技試験**: 100点満点中60点以上（60%）

### 試験科目
1. ライフプランニングと資金計画（年金、社会保険、住宅ローンなど）
2. リスク管理（生命保険、損害保険など）
3. 金融資産運用（預金、株式、投資信託など）
4. タックスプランニング（所得税、住民税など）
5. 不動産（不動産取引、登記、税金など）
6. 相続・事業承継（相続税、贈与税、遺言など）

## 学習のポイント

### 過去問重視
FP3級試験では過去問から類似の問題が多く出題されます。本サイトの問題を繰り返し解くことで、合格率が大幅に向上します。

### 最新法令対応
試験は実施年度の法令に基づいて出題されます。特に以下の項目は最新情報を確認しましょう：
- 税制改正（所得控除額、基礎控除など）
- 社会保険の改定
- NISA制度の変更
- 相続税・贈与税の改正

### 実技対策も重要
学科試験だけでなく実技試験も合格要件です。計算問題や図表の読み取りにも慣れておきましょう。

## 開発者向け情報

### 問題の追加方法

`questions.js` ファイルの `questionsData` オブジェクトに問題を追加できます：

```javascript
{
    id: 1,
    question: "問題文",
    options: [
        "選択肢1",
        "選択肢2",
        "選択肢3",
        "選択肢4"
    ],
    correctAnswer: 0, // 正解のインデックス（0-3）
    explanation: "解説文"
}
```

### カスタマイズ

- `styles.css`: デザインのカスタマイズ
- `script.js`: 機能の追加・変更
- `questions.js`: 問題の追加・編集
